## 🛠️ Free Online Tools

All tools run 100% inside your browser. No accounts, no paywalls, no tracking:

- 🔣 **[Weird Symbols Copy & Paste](https://oddbox.fun/weird-symbols/)** — 2,900+ organized Unicode symbols across 30 categories (aesthetic arrows, stars, hearts, math, currency, brackets, Greek, runes, and astrology).
- 🏷️ **[Cool Name Symbols](https://oddbox.fun/cool-name-symbols/)** — 200+ stylish fonts, frames, and gamer tags for BGMI, Free Fire, PUBG, Discord, and Instagram bios.
- 👻 **[Invisible Text Copy & Paste](https://oddbox.fun/invisible-text-copy-paste/)** — Copy zero-width spaces, hangul fillers, and blank Unicode characters with 1-tap copy, repeat counters (0–100), and test boxes.
- 😀 **[Emoji Copy & Paste](https://oddbox.fun/emoji-copy-paste/)** — 1,800+ standard Unicode emojis with instant keyword search and multi-item preview box.
- (づ｡◕‿‿◕｡)づ **[Kaomoji Copy & Paste](https://oddbox.fun/kaomoji-copy-paste/)** — 360+ classic Japanese emoticons organized by emotion (happy, shrug, table flip, love, flex, sadness).

---

## ✨ Features

- **1-Tap Instant Copy:** Every character copies directly to your clipboard with immediate toast feedback.
- **Repeat Counter (0–100):** Generate repeated symbols or invisible spaces in one click.
- **Global Workbench:** Collect symbols and emojis across tools, preview them together, and copy as a single snippet.
- **Favorites (Offline Storage):** Save frequently used symbols locally on your device without creating an account.
- **Zero Server Latency:** Everything renders and calculates on the client side.
